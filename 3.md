## Data structures (new in V3)

| DS | Role |
|----|------|
| Simple hash table (`key → list[Tuple]`) | Hash join build; optional agg grouping |
| Aggregate state | `COUNT` / `SUM` / `MIN` / `MAX` / `AVG` |
| Sorted runs + k-way merge | External merge sort |
| Plan hints | HashJoin vs NLJ; IndexScan vs SeqScan |
| `Transaction` + TM | txn id, read/commit timestamps, write set |
| `LogRecord` + WAL file | Durable log chain (`lsn`, `prev_lsn`) |
| `UndoRecord` / `VersionMeta` | Abort rollback + snapshot visibility |
| AnalysisResult | Classify committed vs loser txns (recovery step 1) |

Skip for V3: cost-model stats, disk-spilling hash join, window functions, full redo/undo recovery, fuzzy checkpoints.

## Algorithms

| Algorithm | Role | V2 today | V3 target |
|-----------|------|----------|-----------|
| Equality join | Join | NLJ only | **Hash join** |
| Aggregation | GROUP BY | None | **Hash aggregate** |
| Ordering | ORDER BY | None | **External merge sort** |
| Truncation | LIMIT / Top-N | None | **LimitExecutor** |
| Planning | Pick ops | Index eq rule | **Rule-based optimizer** |
| SQL surface | DDL/DML/DQL | CREATE/INSERT/SELECT/JOIN | + GROUP BY, ORDER BY, LIMIT, aggs, **DELETE**, **UPDATE**, **BEGIN/COMMIT/ROLLBACK** |
| Txns | Atomic units | None | **begin/commit/abort** + write set |
| Undo | Abort | None | **UndoLog rollback** |
| WAL | Durability path | None | **append + flush** (WAL-before-data on commit) |
| Recovery analysis | Crash prep | None | **analyze()** committed vs losers |
| Visibility | Snapshot reads | All rows | **`visible()` helper** (wire into scans if time; else V4) |

## Mental pipeline (V3)

```text
WAL file  ←  LogManager.append/flush
                ↑
TransactionManager (begin/commit/abort) ←→ UndoLog
                ↑
Disk ←→ DiskScheduler ←→ Buffer pool
                ↑
Table heap (+ version meta / delete marks)   B+Tree indexes
                ↑
Catalog
                ↑
Plan: SeqScan|IndexScan → Filter → [HashJoin|NLJ]
      → Aggregate → Sort → Limit → Project
      Insert | Delete | Update  (under a Transaction)
                ↑
Database SQL (+ BEGIN/COMMIT/ROLLBACK)
```
